# Brand

Brand assets and guidelines for Joka Source Foundation.

## Contents

| File/Folder | Purpose |
|-------------|---------|
| `logos/` | SVG and raster logo files (mark, wordmark, favicon) |
| `palette.json` | Color definitions — hex, RGB, WCAG contrast ratios |
| `typography.md` | Type system, font stacks, usage rules |
| `voice-tone.md` | Brand voice, messaging principles, hashtag strategy |
| `discovery-questionnaire.md` | Founder pre-work, interview script, and joint discovery workshop |
| `discovery-questionnaire-condensed.md` | Practical breadth-first 30-question founder questionnaire |
| `agency-engagement-plan.md` | End-to-end strategy, identity, experience, activation, and handover plan |
| `strategic-hypotheses.md` | Desk-audit findings and hypotheses to test before permanent creative work |

## Usage Rules

The permanent brand is not yet defined. Current website colors, typography, messages, and identity
choices are provisional until the discovery and strategy gates in `agency-engagement-plan.md` are
completed. Do not convert a draft hypothesis or visual direction into a permanent usage rule.

For questions on brand usage, contact the responsible founder.
