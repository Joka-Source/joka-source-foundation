# CAT Commons

> A trustworthy starting point for CAT aspirants: one guide, a small resource path, and a community that hands the work forward.

## Overview

CAT Commons turns Krishna Chaudhari's *HowToACE - CAT* guide and the community's proven public resources into one maintained path for aspirants. It is designed for the existing learner community and future cohorts who should be able to open one folder, understand the preparation approach, and take their next action without asking for a private resource dump.

The Google Drive folder is the file system of record. This public repository stores governance, provenance, access rules, and verification evidence only. It never stores learner correspondence, application records, credentials, or large course binaries.

## Who it serves

- CAT aspirants who need a clear, realistic preparation path
- Volunteer mentors supporting the current community of roughly 200 learners
- Future cohort leads who need a maintainable handoff rather than a collection of personal Drive links

## First release

The first release must make the following journey work:

1. Open the canonical folder.
2. Read *HowToACE - CAT 1.1* first.
3. Choose a target and preparation plan.
4. Reach the current, rights-cleared resources for VARC, DILR, QA, PYQs, mocks, and community support.
5. Know where to ask for help or report an outdated resource.

Commercial coaching recordings, torrent-derived material, and other files without verified redistribution rights are not part of the public release.
