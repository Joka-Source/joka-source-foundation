# Recommended Watch Order

Sequenced by learning dependency, not publication date:

> how to think -> how to identify problems -> how to build -> how to distribute -> how economics work -> how organisations scale -> how leaders decide -> how all of it behaves in India -> personal operating system

Two-part conversations are kept together and always run Part 1 before Part 2. Where a Part 2 is rated **B** or below you can skip it without losing the module's argument.

**Full curriculum:** 79 watchable videos, ~93 hours.
